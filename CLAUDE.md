# CLAUDE.md — Fintrack

Antes de implementar cualquier tarea en este proyecto:

1. Leer siempre: `ARCHITECTURE.md` — arquitectura general del sistema

2. Leer según el tipo de tarea:
   - Si la tarea involucra código React Native / Expo (componentes, hooks, navegación, WatermelonDB): leer `SKILL-react-native.md`
   - Si la tarea involucra Supabase (Edge Functions, auth, base de datos, RLS, sync): leer `SKILL-supabase.md`

Estos documentos son la fuente de verdad para decisiones técnicas en el proyecto.
